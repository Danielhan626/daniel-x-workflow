# 把一篇笔记变成容易读的长文

写作和发布，可以分成两步。

先把观点写清楚，再处理平台格式。不要为了排版重写整篇文章。

## 整套流程

1. 在本地保留 Markdown 原稿。
2. 检查标题、段落、链接和图片顺序。
3. 导出富文本，在目标编辑器里核对。

> 写清楚 → 排版 → 检查 → 发布。

## 给重点留一点空间

++关键短语++可以划线，**重要判断**可以加粗。

==这句在完整设计版显示为高亮==，在 X 版则保留为加粗。

不要整段标记。留白和清晰的层级，往往比特效更重要。

### 一个小检查

- 标题是否说明读者能获得什么？
- 引用和列表是否还在？
- 图片是否出现在正确的位置？
